# OS Lab — Operating Systems

A collection of Operating Systems laboratory programs written in **Bash** and **C**.

This repository contains shell scripting exercises, process management demonstrations, and CPU scheduling implementations.

## Repository Structure

| Folder                                 | Programs | Topics Covered                                                                                                            |
| -------------------------------------- | -------: | ------------------------------------------------------------------------------------------------------------------------- |
| `01_Basic_Shell_Scripting`             |        3 | Time-based greeting, for loop and word counting                                                                           |
| `02_Conditional_Statements`            |        9 | Even/odd checks, discount calculation, BMI, grade conversion, ticket pricing, leap year, number sign and largest/smallest |
| `03_Loops_and_Number_Programs`         |        8 | GCD, sum of digits, natural numbers, factorial, Fibonacci, palindrome, alternate digits and number reversal               |
| `04_Arrays_and_Command_Line_Arguments` |        2 | Array element sum and arithmetic using command-line arguments                                                             |
| `05_Process_Management`                |        4 | Process creation, `fork()`, `getpid()` and parent-child process IDs                                                       |
| `06_CPU_Scheduling`                    |        2 | First Come First Served (FCFS) CPU scheduling                                                                             |

## Technologies Used

- **Shell:** Bash
- **Programming Language:** C
- **Compiler:** GCC
- **Operating System:** Linux / Unix-like environment
- **System Calls:** `fork()`, `getpid()`, `getppid()` and `wait()`
